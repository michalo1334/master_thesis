# TOP 1 — Weighted mission impact / resilience

## Najważniejszy upgrade całej pracy

Obecnie:
- blast radius = liczba przejętych hostów.

To za mało realistyczne.

## Rozszerzenie

Każdy asset dostaje:
- wagę krytyczności,
- wpływ operacyjny,
- importance score.

Przykłady:

| Asset | Criticality |
|---|---|
| Active Directory | 1.0 |
| Database | 0.95 |
| CI/CD runner | 0.75 |
| User workstation | 0.25 |
| Test VM | 0.05 |

## Efekt

System optymalizuje:
- utrzymanie zdolności operacyjnej,
- resilience,
- mission continuity.

A nie tylko:
- „ile hostów przejęto”.

## Dlaczego to ważne konkursowo

To bardzo dobrze trafia w:
- cyber defense,
- infrastructure resilience,
- military operational thinking.

Projekt zaczyna wyglądać dużo bardziej profesjonalnie.

# TOP 2 — Pokazanie „why CVSS fails”

## Potencjalnie najmocniejszy element naukowy

Nie tylko:
- „mój optimizer jest lepszy”.

Ale:
- „severity-only prioritization strukturalnie zawodzi w interconnected networks”.

## Co pokazać

### Przykład 1

Low severity vulnerability:
- umożliwia lateral movement,
- tworzy strategic bridge node,
- daje ogromny blast radius.

### Przykład 2

High CVSS vulnerability:
- jest izolowana,
- ma mały operational impact.

## Kluczowe obserwacje

- topology dominates severity,
- bridge nodes amplify propagation,
- segmentation can outperform patching,
- local risk != global impact.

## Efekt konkursowy

To pokazuje:
- graph reasoning,
- system thinking,
- operational understanding.

To może być najbardziej zapamiętywana część pracy.

# TOP 7 — Cost-aware optimization

## Obecny stan

Optimizer jest już kosztowy: każda akcja obronna ma koszt, a wybrane portfolio musi zmieścić się w budżecie.

Rozszerzeniem pozostaje pogłębienie modelu kosztów: koszty operacyjne, zależności między akcjami, realistyczne metryki (np. czas rebootu przy patchowaniu).

## Rozszerzenie

Każda akcja ma koszt:

| Action | Cost |
|---|---|
| Patch | low |
| MFA | medium |
| Segmentation | medium/high |
| Disable service | high |

## Efekt

System:
- balansuje security i operacyjność,
- przypomina real cyber decision support.

To bardzo profesjonalny upgrade.
