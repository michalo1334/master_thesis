# Verbose commands

- `mix test` — emits full-suite test output and OpenTelemetry fault-injection logs.
- `npm test` / `npx vitest run` — prints every frontend suite and repeated jsdom CSS parser notices.
- `npm run typecheck` / `npx svelte-check` — scans the complete Svelte and TypeScript tree.
- `mix gen.contracts` — can rewrite and report several generated contract files.
- `playwright-cli snapshot` — can emit a large accessibility tree; use bounded snapshots or Context Mode.
